Usage ​

This section covers all the ways you can use github-code-search effectively.

Guides ​

  • Search syntax — craft precise queries using GitHub code search qualifiers
  • Interactive mode — navigate, filter, and select results in the TUI
  • Non-interactive mode — run in CI pipelines or shell scripts
  • Output formats — produce Markdown or JSON output
  • Filtering — exclude repositories and individual code extracts
  • Team grouping — group results by GitHub team membership
  • Upgrade — keep the binary up to date automatically
